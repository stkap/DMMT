Abstract
Stringent RAM limitations and the absence of hardware accelerators render classical neural networks largely impractical for Continuous Learning tasks directly on microcontrollers. This paper introduces the Dynamic Micro-Matrix Trees (DMMT) architecture—a directed acyclic graph-based method for local learning that entirely eliminates the need for the Backpropagation algorithm. The architecture resolves the catastrophic forgetting problem through organic topological growth (Mitosis) and prevents memory overflow via a deterministic topological refactoring mechanism (Algorithm of Sleep). The result is stable inference and predictable memory consumption with O(1) training complexity under strict hardware constraints.
